# AdShield default blocklist — curated, precision-first (mirip pendekatan
# Cloudflare 1.1.1.1 for Families / Pi-hole yang baik).
#
# ATURAN MATCHING:
#   - "0.0.0.0 domain.com" atau baris polos "domain.com"  -> EXACT MATCH saja,
#     TIDAK ikut memblokir subdomain-nya.
#   - "*.domain.com"  -> wildcard, memblokir domain.com DAN semua subdomainnya.
# Wildcard HANYA dipakai untuk domain yang 100% didedikasikan untuk ad-serving
# (bukan infrastruktur yang juga dipakai untuk hal lain), supaya tidak ada
# konten/app legit yang ikut ke-block karena kebetulan berbagi domain induk.
#
# Sengaja TIDAK memasukkan: crash-reporting/APM (Crashlytics, Sentry,
# Bugsnag, New Relic), product analytics umum (Mixpanel, Amplitude, Segment,
# Hotjar, FullStory) — ini bisa mematahkan fungsi app (laporan crash, fitur
# yang bergantung ke A/B testing, dsb.) tanpa manfaat blokir iklan sama
# sekali. Kalau user tetap mau blokir salah satunya, tambahkan manual di
# layar Aturan Kustom.
